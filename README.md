# AST Table 3 Minimal Reproduction

This repository provides a minimal downstream evaluation package for reproducing the **Baseline** and **Ours** columns in Table 3 of the manuscript.

The package does **not** reproduce neural-network training. Instead, it starts from the saved six-axis IMU outputs produced by the Baseline and Ours models and reproduces the downstream pseudo-GNSS outage evaluation, including the 15-state ESKF, 10 outage seeds, PosErr RMS, and First-3 NIS aggregation.

## Requirements

Python 3.8 or later is recommended.

Install the only required Python dependency:

```bash
pip install numpy
```

## Reproduction command

Run from the repository root:

```bash
python reproduce_table3.py
```

Equivalent explicit command:

```bash
python reproduce_table3.py --data_root ./data --seeds 0-9 --output_dir ./results
```

## Evaluation protocol

For each of the four UZH-FPV test sequences, the script performs the following steps:

1. Loads the raw IMU sequence and the corresponding reference trajectory.
2. Crops the raw IMU to the reference-trajectory time span.
3. Loads the saved corrected IMU sequence using its relative-time representation.
4. Interpolates the corrected IMU onto the cropped raw-IMU time axis.
5. Applies the same small-lag refinement used in the manuscript evaluation.
6. Generates intermittent 1 Hz pseudo-GNSS outage schedules using seeds 0-9.
7. Runs the same 15-state ESKF for Baseline and Ours.
8. Computes PosErr RMS for every sequence/seed run.
9. Computes First-3 NIS for every outage event.
10. Aggregates the results across the 10 outage seeds and all eligible outage events.

The pseudo-GNSS protocol reproduced here is the original manuscript protocol used for Table 3.

## Expected Table 3 values

### PosErr RMS [m]

| Sequence | Baseline | Ours |
|---|---:|---:|
| UZH_Indoor45_9_davis | 3.051 | 2.607 |
| UZH_Indoorforward_9_davis | 9.814 | 4.448 |
| UZH_Outdoor45_1_davis | 2.317 | 4.017 |
| UZH_Outdoorforward_3_davis | 6.576 | 2.366 |

### First-3 NIS [-]

| Sequence | Baseline | Ours |
|---|---:|---:|
| UZH_Indoor45_9_davis | 0.058 | 0.166 |
| UZH_Indoorforward_9_davis | 0.675 | 0.081 |
| UZH_Outdoor45_1_davis | 0.147 | 0.418 |
| UZH_Outdoorforward_3_davis | 0.499 | 0.063 |

Small floating-point differences may occur across Python/NumPy versions, but the reported values should match to the shown precision.

## Output files

After execution, the `results/` directory contains:

```text
results/
├─ per_seed_metrics.csv
├─ per_outage_event_metrics.csv
└─ table3_baseline_ours.csv
```

`per_seed_metrics.csv` contains the run-level results for every sequence, method, and outage seed.

`per_outage_event_metrics.csv` contains the outage-event-level First-3 NIS values and the generated outage intervals.

`table3_baseline_ours.csv` contains the final sequence-level aggregated results corresponding to the Baseline and Ours columns reported in Table 3.

## Scope

This repository is intended for **downstream evaluation reproduction** of the reported Table 3 results.

It does not include the complete neural-network training pipeline. The released IMU files are frozen outputs generated by the corresponding Baseline and proposed compensation models. This package is therefore designed to independently verify the navigation-evaluation results starting from those saved model outputs.
